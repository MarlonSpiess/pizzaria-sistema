# Sistema Integrado da Pizzaria

Planejamento de um sistema de gestão com 9 módulos integrados (RH, Imobilizado, Estoques e Compras, Contas a Pagar/Receber e Fluxo de Caixa, Custos, Vendas, Produção, Fechamento de Caixa e BI), cada um capaz de operar isoladamente. O beta usa dados locais, pronto para migrar para a nuvem.

- `planejamento/00_Plano_Macro.md`: plano macro v0.1 (em discussão, não aprovado).
- `planejamento/apresentacao/`: código-fonte dos slides da apresentação comercial dos módulos e do mapa de integrações.
